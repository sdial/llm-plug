上下文优化

请求转发给上游前，对 tool 输出做确定性压缩，降低输入 token 消耗并提升 Anthropic 缓存命中率。总开关默认关闭，存量行为完全不变。

启用上下文优化 热更新 即改即生效

仅作用于 Chat Completions 与 Anthropic Messages 请求；Responses 请求永远跳过。关闭时所有请求原样转发，压缩管线零开销。

压缩规则（确定性）

规则为纯函数，同一输入永远得到同一输出；只改 tool 结果文本，不碰角色、调用 ID 与工具配对，非文本内容（图片/音频/文件）跳过。

移除 ANSI 转义码

清除终端颜色/光标控制序列，如 \x1b[31m。

清理行尾空白与回车符

去除每行行尾空格、Tab 与 \r。

折叠连续空行

连续多行空行折叠为两行。

去重连续重复行

连续完全相同的行只保留一次。

归一化 Claude Code 遥测 热更新

仅 Anthropic Messages：把 cwd、date、OS、模型元数据等动态值替换为固定占位符，提升 prompt cache 命中率。

Caveman 提示词注入

在 system 提示词头部固定注入 Caveman 指令，让模型用极简短句输出，降低输出 token 成本。注入文本与位置固定，不破坏 prompt cache。

启用 Caveman 模式 热更新

仅 Chat Completions 与 Anthropic Messages 上游生效；默认关闭。
