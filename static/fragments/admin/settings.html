服务信息

零配置启动。服务不需要 .env，容器内固定监听 0.0.0.0:55555，对外访问端口由 Docker 端口映射决定。

首次启动会使用内置默认值。渠道配置写入 data/channels.json，API Key 写入 data/api_keys.json，系统设置写入 data/settings.json。
只要持久化 data/ 目录，所有数据都会随容器重建保留。

热更新
三种动作说明
mask

中间遮星，保留首尾、中间变星号，不可还原。示例：13800138000 → 138****8000；身份证 6 位 + 8 星 + 4 位；邮箱 2 位 + **** + 2 位。

replace

整段替换为 [REDACTED]，不可还原。示例：联系 foo@example.com → 联系 [REDACTED]。

block

命中即拦截整个请求，返回 HTTP 400（Sensitive data blocked by PII filter），请求不会发往上游。

说明：本地轻量正则引擎，零依赖；encrypt 已移除，存量 encrypt 规则静默回退为 mask；豁免渠道（pii_exempt_channels）跳过处理；流式与非流式共用同一管线。
