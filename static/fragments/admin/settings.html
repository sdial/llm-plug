服务信息

零配置启动。服务不需要 .env，容器内固定监听 0.0.0.0:55555，对外访问端口由 Docker 端口映射决定。

首次启动会使用内置默认值。渠道配置写入 data/channels.json，API Key 写入 data/api_keys.json，系统设置写入 data/settings.json。
只要持久化 data/ 目录，所有数据都会随容器重建保留。

请求处理

这些设置影响所有代理入口。

从最后一次收到上游数据开始计时，超过即中断该请求。持续有数据流出的长请求（如推理模型思考、长回复）不会超时；上游心跳/keep-alive 不算数据。

每个流式请求在内存中记录的 SSE chunk 最大数量，用于重建请求日志中的响应体。超过上限后停止记录。

格式转换

时区设置

时区同时作用于前端展示与统计边界：前端页面的时间展示，以及统计日切与"今日"边界。留空使用服务器时区。

前端时间展示与统计日切边界均跟随此时区。IANA 时区名。

请求记录数据库

每次请求都会自动记录基础统计（渠道、模型、耗时、Token 用量、状态码等），无需任何配置。

首页图表使用的聚合统计单独保存在 data/stats.db，请求记录默认保存在 data/request_logs.db，不受此处设置影响。
